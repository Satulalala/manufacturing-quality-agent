# 缺陷代码手册（Defect Code Manual）

## torque_low 扭矩偏低

现象：装配扭矩低于规格下限 40 N·m。
可能原因：扭矩枪校准漂移、工装磨损、批次物料硬度差异、设备换型后参数未更新。
排查步骤：
1. 复核扭矩枪校准记录和最近校准时间。
2. 检查工装磨损和定位精度。
3. 对照批次物料检验报告，确认物料硬度是否异常。
4. 确认换型后扭矩参数是否重新下发。

## pressure_high 压力偏高

现象：装配压力高于规格上限，超出控制线。
可能原因：气源压力波动、夹具变形、节拍过快导致压装不到位。
排查步骤：
1. 检查气源稳压装置和压力传感器校准。
2. 检查夹具变形与定位销磨损。
3. 核对节拍与压力曲线的对应关系。

## temperature_drift 温度漂移

现象：工艺温度连续多日缓慢上升，最终超出控制线。
可能原因：冷却系统效率下降、环境温度变化、加热元件老化。
排查步骤：
1. 检查冷却系统流量与换热器状态。
2. 对比环境温度与工艺温度变化曲线。
3. 检查加热元件功率与老化情况。
